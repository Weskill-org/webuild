## 2024-05-20 - Missing Authorization in Razorpay Edge Function
**Vulnerability:** The `razorpay` Edge Function (`supabase/functions/razorpay/index.ts`) allows any unauthenticated user to call the `release_payment` action and release funds from escrow.
**Learning:** Edge Functions invoked via `supabase.functions.invoke()` need explicit authentication checks (e.g., parsing the JWT token from the `Authorization` header) when performing sensitive operations like transferring funds. Simply using `SUPABASE_SERVICE_ROLE_KEY` bypasses RLS and assumes the backend has verified the request.
**Prevention:** Always verify the caller's JWT token (using `createClient` with `SUPABASE_ANON_KEY` and `auth.getUser(token)`) and ensure they are authorized to perform the action (e.g., verifying they are the owner of the project) before executing sensitive business logic in Edge Functions.

## 2024-05-21 - Unauthenticated send-notification Edge Function
**Vulnerability:** The `send-notification` Edge Function allows any unauthenticated user to trigger arbitrary push notifications and emails (including spoofing messages from other users) because it lacked JWT validation.
**Learning:** Supabase Edge Functions with `verify_jwt = false` bypass the API gateway authentication entirely. They require explicit validation of the `Authorization` header within the function body using `supabase.auth.getUser()`. If the edge function is also triggered by webhooks or other backend services without a user JWT, checking for the presence of the `Authorization` header is crucial. To avoid breaking webhook or backend calls, only validate and enforce the user matching if the `Authorization` header is present. For public endpoints or endpoints triggered by user actions, the missing `Authorization` check allowed unauthorized notification triggering.
**Prevention:** Always parse and validate the `Authorization` header using `supabaseClient.auth.getUser(token)` and enforce authorization checks (e.g., verifying `user.id === user_id` or similar for actions attributed to the caller) in edge functions that bypass the default JWT verification, specifically when the action is initiated by a client directly via `supabase.functions.invoke()`.
