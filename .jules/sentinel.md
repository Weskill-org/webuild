## 2024-05-20 - Missing Authorization in Razorpay Edge Function
**Vulnerability:** The `razorpay` Edge Function (`supabase/functions/razorpay/index.ts`) allows any unauthenticated user to call the `release_payment` action and release funds from escrow.
**Learning:** Edge Functions invoked via `supabase.functions.invoke()` need explicit authentication checks (e.g., parsing the JWT token from the `Authorization` header) when performing sensitive operations like transferring funds. Simply using `SUPABASE_SERVICE_ROLE_KEY` bypasses RLS and assumes the backend has verified the request.
**Prevention:** Always verify the caller's JWT token (using `createClient` with `SUPABASE_ANON_KEY` and `auth.getUser(token)`) and ensure they are authorized to perform the action (e.g., verifying they are the owner of the project) before executing sensitive business logic in Edge Functions.
## 2026-06-28 - [High] Insecure Edge Function Authorization
**Vulnerability:** The `send-notification` Supabase Edge Function configured with `verify_jwt = false` lacked token verification, exposing a potential endpoint abuse where any authenticated (or unauthenticated) client could bypass security by blindly trusting the `user_id` payload field. For the 'message' event, this allowed attackers to impersonate other users.
**Learning:** Supabase Edge Functions with `verify_jwt = false` do not enforce authentication at the gateway. These functions must manually parse the `Authorization` header and validate the JWT using `supabase.auth.getUser()`. Additionally, the `user_id` payload must be strictly validated against the authenticated user for context-sensitive events (like sending messages).
**Prevention:** Always implement manual JWT validation for `verify_jwt = false` endpoints. For events where a user performs an action on their own behalf (like sending a message), implement explicit authorization checks ensuring `user.id === payload.user_id`. Allow `SUPABASE_SERVICE_ROLE_KEY` to bypass this check only for internal backend automation (like Database Webhooks).
