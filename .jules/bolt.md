## 2024-05-28 - Unmemoized Admin Data Grid Filtering
**Learning:** React Admin dashboard views (like `AdminUsers.tsx` and `AdminProjects.tsx`) containing large datasets derived from `supabase` queries were computing multi-field text searches and status/role filtering directly within the render body. This caused the entire list of users/projects to be synchronously re-filtered and repaginated on every keystroke in the search bar, degrading UI performance on large sets.
**Action:** Always wrap heavy synchronous array operations (filtering and sorting of large datasets) and dependent downstream calculations (like slicing for pagination) in `useMemo` hooks with tight dependency arrays (e.g. `[data, search, currentFilter]`). This caches the result between renders when the source data or search terms haven't changed.
