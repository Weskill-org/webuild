## 2026-05-31 - Missing ARIA Labels on Action Buttons\n**Learning:** In the Shadcn UI library, `<Button size="icon">` relies heavily on visual icons without inherent text. Without `aria-label`, these elements are announced as unlabelled buttons by screen readers, creating accessibility barriers for key interactive elements across dashboards and lists.\n**Action:** When implementing or reviewing `<Button size="icon">`, always mandate the inclusion of an `aria-label` or `title` property to provide explicit context to assistive technologies.
