## 2026-05-22 - Icon-only buttons accessibility\n**Learning:** Icon-only buttons (like those used for sending chat messages) lack an accessible name by default, making them invisible or unclear to screen reader users.\n**Action:** Always add an explicit `aria-label` to `<Button size="icon">` components and unlabeled `<Input>` fields to provide clear context.
## 2024-05-23 - Widespread Missing aria-label on Shadcn UI Icon Buttons\n**Learning:** Radix/Shadcn `<Button size="icon">` components frequently omit accessible names when wrapping pure Lucide icons (e.g. `<Trash2 />`, `<Pencil />`, `<Download />`). While visually clear, this renders them invisible or confusing ("button") to screen readers across many dashboard and admin components.\n**Action:** When adding or reviewing icon-only actions (like edit, delete, download, or external links) within tables or lists, always enforce the inclusion of an explicit `aria-label` attribute on the `<Button>`.
